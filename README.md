# XO(Tic-Tac-Toe)Game: Console-Based Player vs Computer
My first project with Java - the XO Game

**Azerbaijani:**
Bu layihə, sadə bir konsol əsaslı XO (Tic-Tac-Toe) oyunudur. Oyunçu və kompüter arasında oynanılır, və oyun konsolda idarə olunur. Oyun başladıqda istifadəçi və kompüter növbəli olaraq "X" və "O" simvollarını oyun taxtasında yerləşdirirlər. Oyun bitdikdə qalib müəyyən edilir və ya heç-heçə olarsa, oyun biter.

**English:**
This project is a simple console-based XO (Tic-Tac-Toe) game. It is played between a player and the computer, and the game is controlled via the console. Once the game starts, the user and the computer take turns placing "X" and "O" symbols on the game board. At the end of the game, a winner is determined, or if the game ends in a tie, it will show a draw.
